# Hospital Performance Analytics Dashboard

## Project Overview

The **Hospital Performance Analytics Dashboard** is an interactive data visualization project developed using Tableau to analyze hospital performance, patient flow, department-level activity, and resource utilization.

The project transforms hospital-related data into meaningful visual insights through interactive dashboards and key performance indicators (KPIs). It helps users understand important performance measures and explore patterns across different hospital operations.

## Objectives

- Analyze overall hospital performance using key performance indicators.
- Monitor patient admissions and patient-flow metrics.
- Compare department-level activity and referrals.
- Analyze hospital resource utilization over time.
- Provide interactive dashboards for exploring hospital data.
- Support data-driven analysis through visual reporting.

## Dashboards

### 1. Hospital Overview
Provides a summary of hospital performance through key metrics, including:
- Total admissions
- Occupancy rate
- Average length of stay
- Readmission rate
- Bed utilization

### 2. Patient Flow
Focuses on patient-related metrics and flow analysis, including:
- Patient count
- Average waiting time
- Average patient age
- Patient-flow trends and comparisons

### 3. Department Analysis
Provides a department-level view of hospital activity, including:
- Department-wise referrals
- Comparison of department activity
- Distribution of referrals across departments

### 4. Resource Utilization
Analyzes resource utilization patterns over time, including:
- Year-wise resource trends
- Resource utilization comparisons
- Historical patterns from 2020 to 2024

## Key Performance Indicators

The project includes the following performance indicators:

| KPI | Purpose |
|---|---|
| Total Admissions | Summarizes the number of recorded admissions |
| Occupancy Rate | Measures bed occupancy according to the defined calculation |
| Average Length of Stay | Summarizes the average duration of hospital stays |
| Readmission Rate | Measures readmissions using the project's defined criteria |
| Bed Utilization | Evaluates bed usage according to the selected definition |
| Average Waiting Time | Summarizes patient waiting duration |
| Average Patient Age | Shows the mean age of eligible patient records |

## Testing and Validation

The dashboard was tested across four major areas:

1. **KPI Calculation Validation** — Checking KPI calculations against the applicable data and calculation definitions.
2. **Healthcare Metrics Verification** — Reviewing metric definitions, units, and consistency.
3. **Dashboard Interaction Testing** — Testing navigation, filters, chart actions, and reset behaviour.
4. **Patient-Flow Analytics Validation** — Reviewing patient counts, waiting-time calculations, average age, and filter responses.

The project includes a dashboard testing report documenting the testing methodology, test cases, recorded values, and results.

## How to Use

1. Clone or download this repository.
