## 🧹 Data Cleaning & Transformation

The **complete data cleaning and transformation process was performed on the original project datasets**.

The cleaning workflow included activities such as:

* **Removing duplicate records**
* **Handling missing values**
* **Standardizing column names**
* **Correcting data types**
* **Standardizing categorical values**
* **Handling outliers and inconsistent values**
* **Creating required fields for analysis**
* **Preparing the processed datasets for Tableau**

The sample files provided in this repository follow the **same overall structure and format** as the corresponding original and processed datasets.
